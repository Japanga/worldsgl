WorldsGL Audio Codec Dependencies
=================================

Put these JARs in one of:
  lib/
  lib/audio/
  audio-libs/

MP3:
  com.googlecode.soundlibs:mp3spi:1.9.5.4
  com.googlecode.soundlibs:jlayer:1.0.1.4
  com.googlecode.soundlibs:tritonus-share:0.3.7.4

OGG Vorbis:
  com.googlecode.soundlibs:vorbisspi:1.0.3.3
  com.googlecode.soundlibs:jorbis:0.0.17.4
  com.googlecode.soundlibs:tritonus-share:0.3.7.4

The engine's AudioCodecSupport automatically adds JARs found in those
folders to the audio provider class loader before using Java Sound.
